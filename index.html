F3·15DIFÍCILcache HTTP
HTTP Client com Cache
Implemente um ApiClient com cache em memória (Map com TTL). Se o cache tiver o resultado e não expirou, retorne sem fazer HTTP. Se expirou ou não existe, faça a request e atualize o cache.
class ApiClient { final _cache = <String, ({String data, DateTime exp})>{}; final ttl = Duration(minutes: 5); Future<String> get(String url) async { if (_cache[url]?.exp.isAfter(DateTime.now()) ?? false) return _cache[url]!.data; // senão: fetch + cache + return } }
💡 Records são perfeitos aqui para guardar {data, expiration} juntos. DateTime.now().add(ttl) cria o timestamp de expiração.
